# Car Dealership — Backend

Серверная часть веб-приложения автосалона.

Backend построен на Node.js и Express, использует PostgreSQL для хранения данных. Реализованы авторизация через JWT, хеширование паролей, загрузка файлов и взаимодействие с frontend.

**Стек:** Node.js · Express · PostgreSQL · JWT · bcrypt · Multer
